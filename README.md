This is a Monthly Billable Report Generator web application built with:

Key Features:

Holiday Management: Checkbox to toggle holiday input field
Leave & Extra Hours Tracking: Collapsible sections to input leaves and extra hours per week
Dynamic Table Generation: Automatically calculates and displays billable hours, working days, and weekly breakdowns
Copy Functionality: Buttons to copy the table to clipboard and prepare email body content
Responsive Design: Uses Bootstrap 5.3.3 for mobile and desktop responsiveness
Main Sections:

Header: Displays current month/year and developer info
Holidays Section: Toggle-able input for holiday days
Leaves & Extra Hours Section: Week-by-week leave and extra hours inputs
Billable Table: Displays working days, leaves, and billable hours calculations
JavaScript Logic:

Generates weeks dynamically based on current month
Calculates billable hours per week and total
Updates table in real-time as user inputs change
Handles copying table data for Excel/email sharing
